EXTENSIBILITY

Custom Validation Rules

Create your own reusable rules using functions.

Example: Even Number Validator

We create a custom rule called even that checks whether a value is divisible by 2. 

addValidator(
  "even",
  value => Number(value) % 2 === 0
);

validate(6, ["even"]);
